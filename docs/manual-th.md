# คู่มือการใช้งาน ระบบเงินสัจจะชุมชน
### สำหรับคณะกรรมการกลุ่มออมทรัพย์ (เหรัญญิก · เลขานุการ · ผู้ตรวจสอบ)
เวอร์ชันแอป 1.0.0 · ฉบับพิมพ์ได้ A4 · อ่านได้ทุกวัย ตัวอักษรใหญ่

---

## 1) ระบบนี้คืออะไร — ทำอะไรได้บ้าง

ระบบนี้คือ "สมุดบัญชีออนไลน์" ของกลุ่ม ใช้บันทึกเงินสัจจะรายเดือน หุ้น ออมรายปี การกู้ การผ่อน ค่าปรับ กองทุนสวัสดิการ และคำนวณปันผลให้อัตโนมัติ

- ใช้งานได้บนมือถือ Android ทุกเครื่อง ไม่ต้องต่อเน็ตก็บันทึกได้ 100% (ออฟไลน์)
- ข้อมูลเก็บในเครื่องเหรัญญิกเป็นหลัก แล้ว "สำรอง" เป็นไฟล์ส่งให้ GitHub ทุกสิ้นเดือน
- 6–12 เดือนแรก ใช้ออนไลน์คู่กับสมุดกระดาษ ตรวจนับตรงกันทุกสิ้นเดือนก่อนส่งสำรอง
- ระบบไม่มีสิทธิ์ "ลบข้อมูลทิ้ง" — แก้ผิดได้ ระบบเก็บประวัติการแก้ทุกขั้นตอน (Audit)

## 2) เตรียมเครื่องครั้งแรก (ทำครั้งเดียว)

1. เปิด Chrome บนมือถือ แล้วเข้าไปที่ลิงก์กลุ่ม เช่น `https://ชื่อคุณ.github.io/sajja/`
2. กดเมนู ⋮ (สามจุด) → **"เพิ่มสู่หน้าจอหลัก"** → จะได้ไอคอนแอป ฿ อยู่หน้าจอมือถือ
3. แตะไอคอนเพื่อเปิดแอป — ครั้งแรกให้กรอกชื่อกลุ่มแล้ว **ตั้งรหัส PIN 4 หลัก** (เหรัญญิก) จำให้ขึ้นใจ ห้ามบอกลูกหลาน
4. เสร็จแล้วจะเจอ "หน้าหลัก" มียอดเงินคงเหลือกลุ่มอยู่ด้านบนสุด

*จำง่าย ๆ: เปิดแอป → ใส่ PIN 4 หลัก → ใช้งานได้เลย*

## 3) เพิ่มสมาชิกใหม่ (1 นาที/คน)

1. แตะเมนู **สมาชิก** → ปุ่มเขียว **+ เพิ่มสมาชิก**
2. กรอก: ชื่อ–สกุล, (ชื่อเล่น/เบอร์โทร/วันเกิด กรอกทีหลังได้), **วันที่เข้ากลุ่ม** (สำคัญ! ใช้คำนวณสิทธิ์กู้กับค่าปรับ), **เงินสัจจะต่อเดือน**
3. แตะ 💾 บันทึก — ระบบให้รหัส S001, S002... อัตโนมัติ
4. อยากให้สมาชิกดูยอด: เปิดหน้า **อื่นๆ → ดูยอดสมาชิก** แตะชื่อของคนนั้นแล้วยื่นมือถือให้ดู (เห็นของคนละของตัวเองเท่านั้น)

การลาออก/พ้นสมาชิก: เปิดหน้าคนนั้น → แตะ "พ้นสภาพ" (ประวัติเงินยังอยู่ครบ) การลบที่ต้องใส่เหตุผลคือ Soft Delete กู้คืนได้เสมอ

## 4) งานประจำเดือนของเหรัญญิก (30 คน ควรเสร็จไม่เกิน 10 นาที)

เมื่อถึงวันประชุมเดือน ให้ทำเรียงตามนี้:

1. **เปิดหน้า "รับเงิน"** แล้วเลือกหัวข้อ 💵 สัจจะ — รายชื่อทุกคนขึ้นมาเป็นแถว
2. ส่งใคร: **แตะปุ่ม "✓ รับ" ข้างชื่อ = เสร็จในแตะเดียว** (ยอดมาตรฐานของแต่ละคน) — ถ้ายอดไม่เท่ากติกาให้แตะ ✎ เพื่อพิมพ์จำนวนเอง ระบบออกเลขที่เอกสารให้ทันทีทุกใบ
3. ครบทุกคนแล้วหรือยัง: แดชบอร์ดจะเขียนว่า "ส่งแล้ว 13/15 คน"
4. สาย/ขาด: แถบสีแดง "ขาดส่ง... ต้องเก็บค่าปรับ" → กด **ออกใบค่าปรับ** ระบบออกใบคนละ 20 บาทเข้ากองทุนสวัสดิการอัตโนมัติ (แก้ตัวเลขได้ในตั้งค่า)
5. **ซื้อหุ้น**: ไปหัวข้อ 🧾 หุ้น → แตะชื่อ → พิมพ์จำนวนหุ้น (หุ้นละ 10 บาท ระบบคิดเงินให้)
6. **ออมรายปี**: หัวข้อ 🐷 ออมปี → แตะชื่อ → รับครบ 120 บาท (แบ่งส่งได้ ระบบทบให้)
7. ลงนาม: พิมพ์ "สรุปส่งสัจจะเดือนนี้" จากหน้ารายงาน ให้ประธาน/ผู้ตรวจสอบเซ็นเก็บไว้คู่กับสมุดกระดาษ

*ถ้าใครส่งที่หน้างานเป็นเงินสด ให้แตะชื่อแล้วกรอก — ไม่ต้องไปแก้งวดเก่า*

## 5) การกู้ยืม (ขอกู้ → อนุมัติ → ผ่อน)

**ขอกู้:** หน้า กู้/ผ่อน → 📝 ยื่นคำขอกู้ → เลือกคน (ระบบเช็คสิทธิ์เขียว/แดงให้อัตโนมัติ: ต้องออมครบ 3 เดือน ไม่ค้างค่าปรับ ไม่มีหนี้อยู่) → ระบุวัตถุประสงค์ เจ็บป่วย (ด่วนสุด) / ค่าเล่าเรียน / อื่น ๆ → กรอกวงเงิน (เริ่มต้น 1,000 บาท อนุมัติเกินได้ที่คณะกรรมการ) → เลือกจำนวนงวด (ไม่เกิน 10) → เลือก **ผู้ค้ำอย่างน้อย 2 คน** → บันทึก = เข้าคิวรออนุมัติ (สีแดงขึ้นหน้าแดชบอร์ด)

**อนุมัติ:** ผู้กู้กด "อนุมัติ + จ่ายเงินกู้" ระบบออกตารางผ่อนให้อัตโนมัติ: ค่างวด = เงินต้น ÷ จำนวนงวด + ค่าบำรุง 2% ของเงินต้น (จ่ายคงที่ทุกงวด) และบันทึกเงินออกจากกลุ่มให้เลย เช่น กู้ 1,000 ผ่อน 10 งวด → จ่ายเดือนละ 120 บาท (ต้น 100 + ดอก 20)

**รับผ่อน:** เปิดสัญญานั้น → 💵 รับชำระ → กรอกยอด (แตะ 120 ได้เลย) ระบบตัด "ค่าบำรุงก่อน แล้วงวดเก่า→ใหม่" ให้เอง ถ้าจ่ายเกินจะเก็บเป็นเครดิตงวดต่อไป ถ้าปิดครบระบบเปลี่ยนเป็น "ปิดบัญชี" เอง

**เตือนล่วงหน้า 3 วัน:** ก่อนถึงวันผ่อน ระบบจะเด้งเตือนที่หน้าแรกอัตโนมัติ (ต้องเปิดแอปค้างไว้ในวันนั้นสักครู่) — หรือให้เลขานุการโทรเตือนตามลิสต์ "สิ่งที่ต้องทำ"

## 6) กองทุนสวัสดิการ (ค่าปรับ + เงินบริจาค เข้ากองทุน)

หน้า อื่นๆ → 🧰 สวัสดิการ

- บันทึก **รับเข้า**: เงินบริจาค / ค่าปรับที่ได้รับชำระแล้ว
- บันทึก **จ่ายออก**: ฌาปนกิจ · ค่าเสียโอกาสเจ็บป่วย (ระบุจำนวนคืน ระบบคิดคืนละ 100 บาท และเตือนถ้าเกินสิทธิ์ 10 คืน/คน/ปี — ให้ประธานเซ็นอนุมัติกรณีพิเศษ) · ทุนการศึกษาบุตร · ภัยพิบัติ
- ยอดคงเหลือกองทุนสวัสดิการจะแสดงบนหน้าแรกเสมอ

หมายเหตุ: กองทุนสวัสดิการแยกรับ–จ่ายไม่ปนกับเงินปันผลตามข้อบังคับทั่วไป (แก้กติกาได้หน้า ตั้งค่า)

## 7) เงินปันผลสิ้นปี (31 ธ.ค.)

1. หน้า อื่นๆ → 🎁 ปันผล → เลือกปี
2. ระบบคำนวณ "กำไรสุทธิ" เบื้องต้นให้ (ค่าบำรุงรับจริง + รายได้อื่น − ค่าใช้จ่ายดำเนินการ) — คณะกรรมการตรวจสอบกับสมุดจริง แล้วพิมพ์ตัวเลขที่ประชุมมีมติลงไป
3. ระบบคำนวณตามข้อบังคับ: **ปันผล = เงินปันผลสะสม × สัดส่วนหุ้น** พร้อมสรุปให้ดูทีละคน + เศษเหลือเก็บเข้ากองทุน
4. ตรวจกับที่ประชุมแล้ว → 💵 บันทึกจ่าย (กดคนละครั้งตอนจ่ายจริง) หรือพิมพ์ประกาศปันผลไปปิดบอร์ด

## 8) รายงานประจำปี (ไม่เกิน 1 นาที)

หน้า อื่นๆ → 📊 รายงาน (เลือกปีด้านบนก่อน)

| รายงาน | ใช้ตอนไหน |
|---|---|
| งบรายรับ-รายจ่าย | ประชุมทุกเดือน/สิ้นปี |
| งบดุล ณ วันสิ้นปี | ยื่นหน่วยงาน/ตรวจบัญชี |
| รายตัวสมาชิกทุกคน | ปิดประกาศ / ตอบข้อสงสัยสมาชิก |
| ลูกหนี้ค้าง | ตามเก็บเงินผ่อน + แจ้งผู้ค้ำ |
| สรุปส่งเดือนนี้ | ใช้เซ็นรับเงินรายเดือน |
| สวัสดิการ | โชว์ที่ประชุมใหญ่ประจำปี |

ปุ่มส่งออก: 🖨️ **PDF/พิมพ์** (มือถือเลือก "บันทึกเป็น PDF"), 📊 **Excel**, 🧾 **CSV** — ทุกหน้าจอใช้ปุ่มเดียวกัน

## 8) หลักฐาน 2 ฝ่าย: สลิป + ตรวจสลิป + เทียบโถะ + ปฏิทินผ่อน

**สลิปทุกรายการเงิน** — ทุกครั้งที่รับ/จ่ายเงิน ระบบออก "เลขที่เอกสาร" (RCPT-2569-0001...) กับ "รหัสตรวจสลิป" 12 ตัว ผูกกับยอดเงินและวันที่ยกเลิกได้ (แก้ยอด = รหัสเปลี่ยน = ของเก่าตรวจไม่ผ่าน) พิมพ์จากชื่อคนในหน้ารับเงิน/เคาน์เตอร์ผ่อน (พิมพ์ 2 ซีก: ต้นขั้วกลุ่ม + ให้สมาชิก)

**ตรวจสลิป** (เมนู อื่นๆ → 🧾 ตรวจสลิป): ผู้ตรวจสอบหรือกรรมการคนไหนก็ได้ รับสลิปจากสมาชิก → กรอกรหัสหรือเลขที่ → ระบบเทียบและแสดงผล 3 แบบ: ✅ ตรงกับบัญชี / 🗑️ ถูกลบหรือยกเลิก (พร้อมชื่อ+เหตุผล) / ❌ ไม่พบ (อาจถูกแก้ยอดหรือของปลอม — เอาจุดนี้ถามเหรัญญิก) ใช้ได้ทั้งตอนประชุมและตอนปิดเน็ต

**เทียบโถะสิ้นเดือน** (ท้ายหน้า "รับเงินเดือนนี้"): หลักรับเงินครบ ให้นับเงินสดจริงทั้งโถะ พิมพ์จำนวน → บันทึก ระบบคำนวณส่วนต่างให้เอง ถ้าไม่ตรงต้องพิมพ์เหตุผล (เงินทอนค้าง/นับผิดรอบต่อไป ฯลฯ) และ หน้าแรกจะคอยเตือนไว้จนกว่าจะแก้ไขเสร็จ

**ปฏิทินผ่อน (.ics)** (หน้า เคาน์เตอร์ผ่อน): กดหนึ่งครั้งได้ไฟล์นัดผ่อนของเดือนถัดไปทั้งกลุ่ม เปิดในมือถือ = เตือนล่วงหน้า 3 วันของทุกคนใน Google Calendar ทันที ไม่ต้องติดตั้งอะไร

## 9) สำรองข้อมูล — หัวใจของระบบ (ห้ามข้าม)

**วิธีที่ 1: ส่งขึ้น GitHub (แนะนำ ทำทุกสิ้นเดือน)**

1. อื่นๆ → ☁️ สำรอง/ซิงก์ → วิธีที่ 1 →ติ๊ก 🔒 ตั้งรหัสผ่าน (จำให้ดี ลืมคือกู้ไม่ได้) → "สร้างไฟล์สำรอง" จะได้ไฟล์ `current-YYYY-MM-DD.enc.json`
2. เปิดแอป Chrome ล็อกอิน GitHub → เข้า repo ข้อมูลของกลุ่ม → โฟลเดอร์ `data` → Add file → Upload files → ปล่อยไฟล์ลง → Commit changes
3. GitHub จะตรวจไฟล์ (Actions) เป็น ✅ ให้ผู้ตรวจสอบมั่นใจว่าข้อมูลครบ
4. *ยังไม่อยากใช้ GitHub ก็ข้ามไปใช้วิธีที่ 2 ก่อนได้*

**วิธีที่ 2: ไฟล์มือถือ→มือถือ (ย้ายเครื่อง/ส่ง LINE)**

- อื่นๆ → 📦 Export ธรรมดา (หรือ 🔐 ตั้งรหัส) → ได้ไฟล์ `sajja-backup-วันที่.json` ส่งเข้า LINE ตัวเอง/ผู้ตรวจสอบ
- เครื่องใหม่: เปิดเว็บแอปครั้งแรก → เลือกเมนู สำรอง → 📥 Import → เลือกไฟล์ → ระบบ "รวม" (merge) ให้เอง ข้อมูลใหม่กว่าจะไม่ถูกทับ

**ตารางสำรองที่ตกลงกันไว้**

| เมื่อไร | ทำอะไร | ใคร |
|---|---|---|
| ทุกสิ้นเดือนหลังประชุม | วิธี 1 (ขึ้น GitHub) | เหรัญญิก |
| ทุก 3 เดือน | วิธี 2 + เก็บลงกล่อง LINE กลุ่มกรรมการ | เหรัญญิก |
| ทุก 6 เดือน | ลองเปิดไฟล์สำรองบนเครื่องผู้ตรวจสอบ | ผู้ตรวจสอบ |

**ย้ายเครื่องทั้งหมด:** เอาไฟล์สำรองล่าสุดมา → ที่มือถือเครื่องใหม่ → เข้าเว็บกลุ่ม → สำรอง → Import → ใส่ PIN เก่า → เลือก "แทนที่ด้วยไฟล์นี้"

## 10) ความปลอดภัยที่ห้ามละเลย

1. PIN = กุญแจ อย่าให้ใคร — เปลี่ยน PIN ทุกครั้งที่คนในคณะกรรมการเปลี่ยน
2. มือถือเหรัญญิกอย่าไปให้ใครกดเล่น; ตั้งล็อกหน้าจอมือถือด้วย
3. ไฟล์สำรองขึ้น GitHub **ต้องเปิด 🔒 เข้ารหัสเสมอ** ตั้งรหัสผ่าน ≥ 8 ตัว อย่าตั้งซ้ำกับ PIN
4. อย่าส่งไฟล์สำรอง (ไม่เข้ารหัส) ผ่านกลุ่มไลน์ใหญ่/อัป Facebook
5. ถ้าใช้ token ซิงก์อัตโนมัติ (ขั้นสูง): ทำตามในเมนู ซิงก์ เท่านั้น และ revoke ได้ทุกเมื่อที่ GitHub → Settings
6. เครื่องหาย: ล็อกเครื่องจาก Find My Device แล้วใช้ไฟล์สำรองล่าสุด import ลงเครื่องใหม่ ข้อมูลที่แก้ไขหลังจากสำรองครั้งล่าสุดต้องบันทึกใหม่จากสมุดกระดาษ

| เปิดแอปแล้วขาว/ค้าง | ล้างแคช Chrome แล้วเข้าเว็บใหม่อีกครั้ง |
| ใส่ PIN แล้วไม่เข้า | ผิด 4 ครั้งต้องรอ — ลืม PIN? ผู้ตรวจสอบ import ไฟล์สำรองลงอีกเครื่องเพื่อทำงานต่อ แล้วเหรัญญิกตั้ง PIN ใหม่ |
| บันทึกผิด / ผิดคน / ยอดผิด | หน้า Audit (ประวัติการแก้ไข) → แตะรายการ → "ลบรายการที่ผิด" หรือ "กู้คืน" แล้วบันทึกใหม่ (ใส่เหตุผลสั้น ๆ ทุกครั้ง เช่น "สะเพร่ายอด") |
| ผู้กู้ผ่อนเกินงวดที่ระบุ | ระบบจะคำนวณ "เครดิตเหลือตัดงวดถัดไป" ไว้ให้ ไม่ต้องแก้อะไร |
| ไฟล์สำรองเปิดไม่ได้ | ไฟล์ .enc.json ใช้ปุ่ม Import เดียวกัน แล้วพิมพ์รหัสที่ตอนสำรอง |
| เครื่องสองเครื่องรับเงินไม่ตรงกัน | เครื่องที่ 2 export → เครื่องที่ 1 import แบบ "รวม" ระบบจะเก็บรายการใหม่ที่สุดเอง |
| อินเทอร์เน็ตล่ม | ใช้ต่อได้เลย ทุกอย่างทำงานออฟไลน์ รอเน็ตแล้วค่อยสำรอง |

## 12) เช็กตัวเอง (ใช้เกณฑ์การยอมรับของคณะกรรมการ)

- ☐ เหรัญญิกบันทึกออม 30 คนเสร็จใน 10 นาที (ใช้ปุ่ม "เก็บครบทุกคน")
- ☐ ปันผลคำนวณตามสูตรกลุ่ม 100% (ตรวจกับสมุดก่อนอนุมัติเสมอ)
- ☐ สมาชิกดูยอดตัวเองผ่านมือถือเหรัญญิก ได้ (เมนู ดูยอดสมาชิก)
- ☐ ออกรายงานงบทดลอง + ปันผล ส่งที่ประชุมได้ใน 1 นาทีจากเมนูรายงาน
- ☐ ปิดเน็ตทั้งบ้าน แล้วแอปยังบันทึก/ดูยอดได้ (ลองเลย)
- ☐ ผู้สูงอายุทำตามคู่มือหน้า 2 แล้วใช้งานได้โดยไม่ต้องอ่านไอที
- ☐ GitHub Actions ทำงานผ่าน ✅ ทั้ง 3 ไฟล์ (deploy / validate / backup)
